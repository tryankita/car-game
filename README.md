# Car Game

A fast, fun browser racing game built with React, Vite, and Three.js.

This project has two modes:
- Arcade mode for quick action
- Track Race mode for lap-based racing

## Quick Start

1. Install dependencies
   npm install
2. Start dev server
   npm run dev
3. Build for production
   npm run build
4. Preview production build
   npm run preview

## Why this project

This game is made to feel simple and fun:
- smooth controls
- mobile-friendly HUD and touch buttons
- lightweight screen-based flow (only loads what you open)

If something feels off on your device, open an issue and share your phone model + browser version.
